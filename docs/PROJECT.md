## 1. 배경

기존 홈페이지는 노션 페이지였다.
```
lab.hufs.ac.kr/pmi  ──302──▶  repeated-velvet-104.notion.site/PMI-Lab-HUFS-...
```
`lab.hufs.ac.kr`은 공대 연구실들이 함께 쓰는 학교 리다이렉트 시스템(최상단은 관리자 로그인 화면)이고,
PMI Lab은 `/pmi` 경로 하나를 배정받아 노션 주소로 넘기고 있었다. 노션 주소는 자동 생성된 이름이 그대로
노출되고, **사이트가 먹통이 되면서 갱신이 멈췄다** (소식 마지막 2025-09-03, 갤러리 마지막 2026-02-20,
멤버 명단은 현행과 불일치).

> 초기 분석에서 공백 원인을 "기록 습관 부재"로 추정했으나 **실제 원인은 사이트 먹통**이다(담당자 확인).
> 멤버 명단 불일치도 같은 원인. 관리 소홀로 해석하지 말 것.

## 2. 구축 방안 검토

학교는 홈페이지 서버를 제공하지 않는다. 동적 사이트(관리자가 웹에서 직접 수정)가 필요하므로 서버가 있어야 한다.

| 방안 | 내용 | 결과 |
|---|---|---|
| A | 정적 호스팅(GitHub Pages) + DNS 레코드 | 동적 불가 → 탈락 (B·C 모두 막힐 때의 차선책이었음) |
| B | 연구실 PC + Cloudflare Tunnel (포트 개방 없음) | **네임서버 위임 불가**로 탈락 |
| C | 연구실 PC + 공인 IP + 80/443 개방 | **승인 → 채택** |

노션 유료 커스텀 도메인(연 13만~80만원)은 비용 최소화 조건과 "재구축" 취지에 맞지 않아 제외.

## 3. 전산실(정보전략팀) 협의

**1차 (2026-09-10 회신)** 네임서버 위임 불가 · 공인 IP/80·443 가능 · DNS 레코드 설정 가능 ·
도메인 관리 주체는 공대 연구실(등록은 정보처, 현재 정보전략팀 관리) · 변경은 신청서로 반나절.

**2차 (2026-09-10 회신)** `pmi.hufs.ac.kr` 사용 가능 · IP 할당은 첨부 신청서 작성 후 회신 ·
`/pmi` 연결 변경은 정보전략팀이 처리(hufs-admin 불필요) · 백신 의무 · 취약점 점검 대상 아님 ·
사고 시 정보전략팀 연락 · 불법 용도 시 강제 회수 및 처벌.

**현재:** 공인 IP 신청서 작성·회신 대기 (배포 담당). 서버 PC에 이미 공인 IP(220.67.128.37)가
붙어 있는 것으로 보여, 고정 여부와 인바운드 개방을 함께 문의하기로 함. 세부는 `SERVER.md`.

## 4. 결정 사항

### 기술
| 결정 | 이유 |
|---|---|
| Django 서버 렌더링 | 관리자 화면 자동 생성이 목적과 정확히 일치. 지원자가 검색으로 유입되므로 SSR이 유리 |
| `lab` 앱 하나 | 전담 개발자 없음. 구조가 단순해야 후임·AI가 유지보수 가능 |
| SQLite | 소량 데이터. 백업·이전이 파일 복사 |
| Caddy | HTTPS 자동. 설정 최소 |
| 전 항목 관리자 관리 | Django Admin에선 항목 추가 비용이 거의 0. "노션에서 고칠 수 있던 건 전부 고칠 수 있어야" |
| 연구 데모·게시판·문의폼·통계 제외 | 1차 범위 밖. 가동 후 필요하면 추가 |
| 논문·프로젝트 파싱 보류 | 표기 불일치 심함. 원문 보존 후 2차 |
| 파일명 ASCII | NFD/NFC 한글 정규화 충돌 실사고 |
| 서버 PC | `juneyonglee-titanxp` (GPU 연구 용도 종료, 웹서버 전용) |

### 연구실 회의 (완료)
| 안건 | 결정 |
|---|---|
| 공백기 처리 | **공백 인정** — 과거 그대로, 오픈일부터 다시 쌓음. 소급 보강 안 함 |

| 국문/영문 | **전환 버튼 — 나중에 도입.** 데이터는 지금부터 `_ko`/`_en` 분리 |
| 현재 멤버 명단 | 손성원이 관리자 화면에서 직접 정리 |
| 역할 | 코드 손성원 · 배포 별도 담당자 |
| 디자인 시안 | 확정 (파일 미전달) |
| 담당자·업로드 주기·추가/삭제 콘텐츠 | 결정됨 — **세부 내용 미기록, 손성원에게 확인** |

## 5. 작업하며 겪은 함정 — 같은 실수 반복 금지

1. **한글 파일명.** macOS는 NFD, Linux는 NFC. 같은 이름이 다른 폴더로 인식돼 쓴 파일이 사라진 것처럼
   보였다. → 경로는 전부 ASCII.
2. **노션 첨부 URL은 5분 만료**(`X-Amz-Expires=300`)이고, Claude 작업 환경에선 노션 S3 호스트가
   이그레스 정책으로 막혀 직접 다운로드가 안 됐다. → 노션 재추출이 필요하면 **Export**(Markdown & CSV,
   하위 페이지 포함, 데이터베이스 보기 = **기본 보기**)를 쓰고 `*_all.csv`와 `*.csv`를 대조해 누락 확인.
3. **노션 두 멤버 DB는 별개 data source이고 내용이 다르다**(홈 7명 / Members 4명, 겹치는 사람 2명).
   처음엔 "우연히 같다"고 잘못 봤다. Export로 대조해서 발견.
4. **노션 Export 날짜 형식이 DB마다 다르다** (`12/18/2024` vs `2026년 2월 20일`).
5. **멤버 Status 다중선택에 직함과 진로가 섞여 있다** ("Master Student" + "취업").
6. 서버 PC SSH는 **15232번**. 방화벽 켤 때 먼저 허용하지 않으면 원격 접속이 끊긴다.
